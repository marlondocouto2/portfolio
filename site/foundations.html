Machine learning foundations

Short projects on core machine learning concepts, applied to real public data outside finance.

Each one takes a few core ideas, such as regression, classification or overfitting, and uses them to answer a real question, in a single notebook with scikit-learn. They are smaller than the main projects, and built the same careful way.

How each one is built

  1. Real public data, outside finance, to try the ideas on something new.
  2. A decision at each step, written down first: what to predict, which features, which mistake costs more.
  3. Simple guesses to beat, like the typical price of similar listings, before any model.
  4. A test set used once, at the very end, so the final score is honest.
  5. Tests for what could go wrong, like data from the same host leaking between training and testing.
