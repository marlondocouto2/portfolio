How each project is built

  1. Start with data where I know the right answer, so I can check the model got it right. Then repeat on real data.
  2. Start with the simplest model, and compare it with obvious shortcuts like "same as last week".
  3. Improve one thing at a time, so it's clear what each step adds.
  4. Test on past data as if it were live: the model only ever sees data up to the day it forecasts.
  5. Show the result in dollars, like how much less cash a company needs to keep on hand.
Most data here is simulated, so the right answer is known; real data is labelled on each page. Code for every project is on GitHub.
