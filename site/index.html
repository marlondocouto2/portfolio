Forecasting portfolio

Forecasts you can explain, measured in dollars

A series of treasury forecasting projects, each built from scratch on synthetic and public data. Every project starts simple, adds one fix at a time, and measures what each step is worth with a walk-forward backtest and a dollar metric.

How each project is built

  1. Simulate data with known structure, so each model component can be checked against the truth, and run the same pipeline on public U.S. Treasury data.
  2. Start from a simple, explainable model and compare it with naive baselines.
  3. Add one fix at a time, each aimed at a specific kind of day the previous version gets wrong.
  4. Measure with a walk-forward backtest: refit at every origin, never use data from the future, and report errors by type of day.
  5. Translate into dollars: the cash buffer needed to cover shortfalls, and the cost of idle cash.
All data on this site is simulated unless marked as U.S. Treasury data. Code for every project is on GitHub.
